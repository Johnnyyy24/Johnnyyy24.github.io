台灣的業餘籃球假日聯盟日漸盛行，尤其在台北的核心地區，每個週末熱門球館，如和平暖身球館，往往大半天都被假日聯盟租掉來消耗比賽。我自己打假日聯盟也邁入第 7 個年頭，很好奇經營這樣一個聯盟大概的營收規模、成本架構長什麼樣子，因此有了這篇文章。

以下，我將以台灣最大的假日聯盟 TGB 為例，來粗淺分析他們如果是一家公司，一年能賺多少錢。

---

**先算一場比賽的成本**

TGB 的場地主要在和平籃球暖身館，每場打一個小時，場地費 2,000 NTD。加上裁判、記錄台、攝影師，一場比賽的成本長這樣：

```
場地費（1小時）              2,000 NTD
裁判費（2人）                1,000 NTD
記錄台＋工作人員（4人）      1,000 NTD
攝影師（1人）                  300 NTD
────────────────────────────────────────
每場總成本                   4,300 NTD
```

裁判部分，業餘聯賽通常配置 C 級裁判，依中華民國籃球協會的規範，C 級裁判的費用大約落在 **500 NTD/場/人**，兩位共 1,000 NTD。C 級是台灣籃球裁判認證的入門級別，能主持一般業餘聯賽的比賽。

記錄台與工作人員的薪資，則參考 TGB 背後公司夢想啟程文創有限公司於 104 人力銀行刊登的[徵才資訊](https://www.104.com.tw/company/1a2x6bndkz)估算。

---

**一組打一季，賺多少？**

每組平均 6 隊，報名費 **26,000 NTD/隊**。賽制是循環賽加四強，場次算法如下：

- 循環賽：6 隊各打一次，C(6,2) = **15 場**
- 四強賽 + 冠軍賽：**3 場**
- **每組共 18 場**

```
收入：6 隊 × 26,000     = 156,000 NTD
成本：18 場 × 4,300     =  77,400 NTD
────────────────────────────────────────
每組毛利                =  78,600 NTD
毛利率                  ≈ 50%
```

---

**放大到全年**

TGB 一年跑 2.5 季，每季約 50 個組別，全年合計 **125 組**。

```
年收入：125 × 156,000   = 19.5M NTD
年變動成本：125 × 77,400 =  9.7M NTD
年毛利：125 × 78,600    =  9.8M NTD
```

在以最低的運營人力來維持這個聯盟的假設下，我粗估一年運營這個聯盟大概還會有這些開支：

```
全職人員（2-3人）            1,500,000 NTD
網站＋系統維護                 200,000 NTD
保險                           200,000 NTD
行銷＋社群經營                 300,000 NTD
雜支（會計、法律、辦公）       300,000 NTD
────────────────────────────────────────
營運費用合計                 2,500,000 NTD
```

```
年毛利                      =  9.8M NTD
營運費用                    = -2.5M NTD
────────────────────────────────────────
估計年淨利                  ≈  7.3M NTD
```

---

根據以上粗淺的分析，TGB 大概是一個毛利在 50%、淨利潤率在 37% 的生意。在這個生意中，比較困難的是長期租到讓大家想打的好球場，以及初期的行銷來建立好的 Brand Name，在運營轉起來的情況下實際上是一個好的生意模式。
